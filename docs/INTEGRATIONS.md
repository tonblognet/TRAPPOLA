# Интеграции

## Аналитика

События уже подготовлены:

- `product_view`;
- `collection_filter`;
- `add_to_cart`;
- `checkout_start`;
- `order_submitted`.

После создания счётчика укажите публичный ID в `VITE_YANDEX_METRIKA_ID` и добавьте официальный загрузчик Метрики только после согласования политики cookie/персональных данных.

## Оплата

До выбора юридического лица, платёжного провайдера и онлайн-кассы подключать оплату нельзя. Секретные ключи должны храниться только на сервере. Браузер получает ссылку или токен платежа от backend после серверной проверки цены и остатка.

## Доставка

Для интеграции нужны договор и API-доступ перевозчика, адрес отправления, допустимые регионы и правила расчёта. Расчёт доставки должен происходить на сервере.

## Уведомления

После backend можно подключить email/Telegram-уведомления о новом заказе. Токены бота и SMTP-ключи нельзя помещать в frontend или GitHub Pages.
