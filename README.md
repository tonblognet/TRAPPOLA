# TRAPPOLA

Интернет-магазин бренда TRAPPOLA на React, TypeScript и Vite. Текущая публикация работает на GitHub Pages как техническая демонстрация без реального списания денег и серверной передачи персональных данных.

## Запуск

```bash
pnpm install
pnpm dev
```

Проверка перед публикацией:

```bash
pnpm check
```

Команда запускает ESLint, unit-тесты, TypeScript и production-сборку. После сборки создаётся `dist/404.html`, чтобы прямые ссылки на страницы работали на GitHub Pages.

## Маршруты

- `/` — главная;
- `/catalog` — каталог и фильтры;
- `/product/:slug` — карточка товара;
- `/about`, `/delivery`, `/returns`, `/contacts` — контентные страницы;
- `/privacy`, `/offer` — юридические шаблоны;
- `/checkout` — демонстрационное оформление;
- `/studio` — локальная контент-студия, не защищённая CMS.

## Данные

Начальный каталог находится в `src/content/catalog.ts`. Локальные изменения студии, корзина и тестовые заказы сохраняются в `localStorage` с версией схемы.

Контент-студия не изменяет общий сайт и не является защищённой админкой: экспортированный JSON нужно перенести в проект или будущий backend. Секреты и реальные ключи нельзя помещать в `VITE_*` переменные — они доступны посетителю сайта.

## Публикация и backup

Ветка `main` автоматически публикуется через `.github/workflows/deploy.yml`.
