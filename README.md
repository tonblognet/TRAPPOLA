# TRAPPOLA

Интернет-магазин бренда TRAPPOLA: React/Vite-витрина, Node.js API, защищённая админка и PostgreSQL. Текущая публикация на GitHub Pages остаётся технической демонстрацией без передачи персональных данных; полная версия подготовлена для российского VPS.

## Запуск

```bash
pnpm install
pnpm dev
```

API для локальной разработки запускается отдельно и требует PostgreSQL:

```bash
pnpm dev:api
```

Проверка перед публикацией:

```bash
pnpm check
```

Команда запускает ESLint, unit-тесты, TypeScript и production-сборку. После сборки создаётся `dist/404.html`, чтобы прямые ссылки на страницы работали на GitHub Pages.

## Маршруты

- `/` — главная;
- `/catalog` — каталог и фильтры;
- `/product/:slug` — карточка товара;
- `/about`, `/delivery`, `/returns`, `/contacts` — контентные страницы;
- `/privacy`, `/offer` — юридические шаблоны;
- `/checkout` — демонстрационное оформление;
- `/studio` — локальная контент-студия только в демо-сборке;
- `/admin` — защищённая серверная админка в API-сборке.

## Данные

Начальный демонстрационный каталог находится в `src/content/catalog.ts`. В API-режиме товары, варианты, остатки, изображения, настройки, администраторы и заказы хранятся в PostgreSQL. Корзина остаётся в браузере, но цена и наличие повторно проверяются сервером при заказе.

Секреты и реальные ключи нельзя помещать в `VITE_*` переменные — они доступны посетителю сайта. Серверные секреты хранятся только в `.env.production` на VPS.

## Публикация и backup

Ветка `main` автоматически публикуется через `.github/workflows/deploy.yml`.
